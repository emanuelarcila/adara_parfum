# Fotografías de producto

Coloca aquí únicamente imágenes autorizadas de ADARA PARFUM. Actualiza `products.js` con la ruta relativa y texto alternativo preciso de cada archivo. Se recomiendan imágenes WebP o AVIF con el producto completo y proporciones fieles. Las imágenes de campaña pendientes se muestran como composiciones CSS en la página.
